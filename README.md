# Academic Skills

Two academic review skills for coding agents:

- [LaTeX bibliography audit](skills/latex-bib-audit/SKILL.md): metadata and citation identity by default; claim support only by explicit opt-in.
- [Academic prose audit](skills/academic-prose-audit/SKILL.md): contextual phrasing and register review with locatable, meaning-preserving suggestions; not AI-authorship detection.

**Codex install:**

```text
$skill-installer Install both skills from JJYDXFS-Lab/academic-skills:
skills/latex-bib-audit and skills/academic-prose-audit.
```

Restart Codex, then check `/skills`. Reviews leave manuscript and bibliography files unchanged and write reports to a separately chosen location. See [install, update and use](docs/README.md#install-and-use) for access, other agents, optional helpers and a first-use prompt.
