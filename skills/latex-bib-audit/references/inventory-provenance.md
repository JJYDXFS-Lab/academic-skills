# Inventory and provenance

Record each input file's absolute path, SHA-256 of its bytes, size and nanosecond mtime before inspecting findings; Git HEAD is helpful context, not a prerequisite or substitute for content hashing. If a file changes, repeat the relevant scan and do not combine findings from different snapshots. Never send private prose to a public endpoint. Mark nonexistent inputs, macro-generated paths, dynamic resources, unsupported cite variants, malformed TeX and stale `.aux`/`.bcf` as coverage gaps.

`scripts/citation_inventory.py` follows literal `\input`, `\include` and `\subfile` references and scans local `file:line` citation keys; it does not expand TeX macros or execute LaTeX. Treat results as preliminary, especially for multiline commands, verbatim/comment environments, BibLaTeX citation variants and multiple Bib files. Fresh `.aux`/`.bcf` results corroborate but never substitute for source. `\nocite{*}` does not demonstrate a prose citation. Check `crossref` and `xdata` dependencies for both referenced and unused entries. No HTML report is generated by the helper.

For read-only local comparison, install `pybtex` **only when separately authorized** in a project-local isolated environment, for example `python3 -m venv .venv && .venv/bin/python -m pip install pybtex`, then use the venv Python to run `scripts/compare_candidates.py` or `scripts/citation_inventory.py`. Neither script installs packages. Parser preflight catches duplicate entry keys and per-entry case-folded duplicate field names; preflight is not a replacement for parsing. Check parser integration on real BibTeX before asserting complete coverage. Do not execute TeX from untrusted projects.
