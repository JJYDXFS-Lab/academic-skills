# Synthetic L3 calibration cases

All names, prose, and evidence summaries below are invented. They are not quotations or findings about real papers. When evaluating a skill revision, give an independent reviewer the claim and evidence columns first, then compare its scoped judgment against the expected boundary. Explain disagreements; a text-matching test cannot establish semantic correctness.

| Case | Claim and citation placement | Available original evidence | Status and rationale |
|---|---|---|---|
| Local insertion | “Shared spaces—scaled by PairNet [A]—enable image search and motivate audio interfaces.” | A establishes large-scale image–text alignment, not audio. | **Directly supported:** for the inserted attribution; do not charge A with proving the later audio application. |
| Collective background | “Contrastive graph learning uses views such as edge deletion and attribute masking [A]; other designs contrast sampled tokens [B].” | A implements deletion/masking; B implements token contrast and discusses augmentation in related work. | **Directly supported:** each citation supports its adjacent clause; B need not implement A's augmentations. |
| Explicit mechanism | “TokenNet creates its views by deleting edges [B].” | B explicitly uses token sampling without graph augmentation. | **Contradicted:** broad membership in graph contrastive learning does not repair this attribution. |
| Capability versus release | “In June, OmniNet introduced a model accepting speech, text, images, and video [C].” | June announcement confirms these model inputs; public interfaces ship in stages. | **Directly supported:** simultaneous availability was not claimed. |
| Concrete numeric input | “SequenceNet renders measurements as charts for its visual encoder [D].” | D embeds scalar measurements with a gated feed-forward block; a separate frozen text encoder supplies labels. | **Contradicted:** a shared neural component does not make the input visual. |
| Optional detail | “IndexNet learns temporal representations [E].” | E uses learned time indices and two auxiliary losses. | **Directly supported:** failure to list both losses is not a missing qualification. |
| Material condition | “Model F improves accuracy on both clean and corrupted inputs [F].” | F improves only on corrupted inputs and loses accuracy on clean inputs. | **Contradicted:** the reported clean-input loss conflicts with the claimed clean-input improvement. |
| Explicit numeric range | “Compression reaches 12-fold [G].” | G's relevant table and appendix cap the reported result at 7-fold under the claimed setting. | **Contradicted:** the stated result conflicts with the reported maximum in the same version and setting. |
| Missing excerpt coverage | “Tokenizer H transfers across sampling rates [H].” | Abstract omits rates; the transfer section explicitly evaluates differing rates. | **Directly supported:** after reading the relevant section; the abstract's omission is not a support gap. |
| Future proposal | “A future benchmark should include text-guided image search [I, J].” | I implements the task; J benchmarks image-only retrieval and explicitly proposes text-guided extensions. | **Directly supported:** I supplies an implemented example and J the proposed direction; do not infer that J already implements the proposed task. |
| Theorem quantifiers | “Theorem K proves every channel fails simultaneously [K].” | K proves each channel has some probability of failing, and at least one fails with high probability. | **Unable to verify:** the supplied theorem does not establish the explicitly claimed simultaneous failure. A weaker theorem alone does not refute the stronger proposition; no incompatible evidence is given. |
| Inspectable gap | “Evaluator L explains mean pooling through feature collapse [L].” | Relevant full-text methods and results concern human evaluation protocols; no inspected passage supports the pooling mechanism. | **Unable to verify:** relevant passages were inspected but supply no support for this mechanism. Record that support gap, not an access failure or an invented replacement; keyword absence alone is insufficient. |
| Restricted support | “Model M improves accuracy across datasets [M].” | M establishes improvement only for balanced datasets, with no result for imbalanced ones. | **Supported with qualification:** restrict the claim to balanced datasets. Unstudied settings are not contradictory evidence. |
| Unrelated member of a group | “Edge deletion supplies contrastive graph views [A, X].” | A establishes that mechanism. Inspection of X's methods, results, and relevant background finds only speech transcription, with no contribution to the graph-view claim. | **Directly supported** for A; **Unable to verify** for X, with an inspected support gap. A's support cannot validate X's inclusion; do not call the graph-view claim false. |
| Inaccessible source | “Method N improves retrieval [N].” | The relevant original paper cannot be accessed; only a metadata record is available. | **Unable to verify:** source-access gap; no claim-support judgment can be established from metadata. |

Use only the four formal statuses above. Within **Unable to verify**, record whether the reason is inaccessible/insufficient evidence or relevant passages inspected without finding support. These reasons are not additional statuses, and neither implies **Contradicted**. If a manuscript omits a qualifier such as “simultaneously,” do not insert it while assigning the citation's responsibility; the theorem case above explicitly includes it.
