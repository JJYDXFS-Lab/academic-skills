# Synthetic examples and severity context

These invented records show report structure, not inspected source evidence. Severity is contextual and confidence is separate: wrong-work for a central result is potentially critical, while an uncited style discrepancy is low; uncertain source identity lowers confidence rather than silently downgrading impact.

Status `unverified mapping`; severity **high** (central result may cite the wrong work), confidence **medium** (key and item title differ; primary paper not inspected). Evidence: local citation resolves to a survey, not an identified Method M primary paper; **no claim-support verification was performed**. DOI is an illustrative placeholder, not a checked source. Proposed action: owner checks intended paper identity; support verification requires separate Layer 3 opt-in. Related L1 identity finding should link here without recounting the same concern.
