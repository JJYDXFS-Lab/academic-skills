# Parallel review (conditional)

Delegate only when available under host/project policy, for bounded independently owned sections; do not spawn solely because this reference exists. Give each reviewer the same exact revision, file hashes, glossary, reporting language, exclusion list and read-only/privacy rules. Permit neighboring context but assign findings to only one section. Require each to return locations, context, minimal suggestions or author questions, deliberate nonissues, gaps and failure receipts. One coordinator compares cross-section templates and terminology, reconciles duplicate or conflicting findings and confirms input revision still matches. If files change mid-review, recheck affected sections or report incomplete coverage; never blend snapshots. No concurrent source edits or final-report writes. Bibliography Layers 1/2 may work alongside on the same fixed revision but provide no original-paper claim verdict; Layer 3 requires distinct opt-in.
