# Safety and coverage

- Pin authorized local input paths and hash raw bytes with SHA-256; record filesystem mtime and, if relevant, Git HEAD separately. A HEAD alone does not identify an uncommitted file. Never transmit unpublished content or private locator output, and never compile untrusted TeX with shell escape.
- The optional locator accepts explicit UTF-8 `.tex`, `.md`, `.txt` paths only, validates all before stdout and never writes input. It masks citations, labels, math, verbatim, comments, quotations, Markdown code/links, Pandoc `[@key]` / `[-@key]` / `@key` citations and HTML comments (including Markdown-like syntax in `.txt`). It exposes common authored TeX prose arguments (`emph`, `textit`, `textbf`, `footnote`, `caption`, `section`, `subsection`, `paragraph`), including starred forms and long titles after optional short titles; short-title arguments are masked and need manual review. Prose in `figure`, `figure*`, `table`, `table*`, `theorem`, `proof`, `remark`, `minipage`, `center` is exposed, while `tabular`, math, verbatim and unknown environments stay masked. Naked brace groups are not automatically discarded. Markdown HTML tags/attributes, reference definitions, complex or malformed Pandoc citations, escaped math delimiters, currency `$`, unsupported macros, generated input and ambiguous nesting are not fully parsed: inspect manually and record gaps rather than claiming a coverage percentage.
- Literal quotations are masked; an unmatched straight `"` fails the entire file closed even when it is typography/inches rather than a quotation (TeX `\"` accents and digits immediately before `"` are special-cased). This deliberate false-negative tradeoff needs manual review. Record unclosed recognized spans as scan failures; the tool does not certify the rest of a failed file. Do not treat stderr skipped counts as coverage. No automated TeX/Markdown scanner can prove all prose seen.
- The locator's questions are neither ban lists nor source-support, scientific, authorship or originality judgments. CLI output is not an audit report.
